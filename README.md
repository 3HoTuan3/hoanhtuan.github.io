# Công nghệ đang dùng trong đồ án

Dự án hiện tại **không dùng React**.  
Code đang được triển khai theo kiểu:

- `index.html` (HTML)
- `src/css/style2.css` (CSS, có `@import "tailwindcss"`)
- `src/scripts/*.js` (JavaScript thuần)

Ngoài ra có cấu hình `tailwind.config.js` và PostCSS, nên có sử dụng Tailwind trong quá trình build, nhưng đây **không phải** dự án React.
